Fleur first run on a fresh Mac

A throwaway prototype for Wayfinder ticket "Prototype the first-run transcripts for a human and for an agent on a fresh Mac". It mocks the terminal output; nothing here runs Fleur or Docker.

The question. Starting from a Mac that already has Bun and Docker Desktop installed, what does a person see when they run bunx @hazeion/fleur, what does a coding agent see when it drives the same journey with --json, and where exactly does authority hand from the agent to the human and back? Everything marked proposed is new behaviour to decide on; everything else mirrors what the CLI does today.
